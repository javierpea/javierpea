<summary><b>🛠️ Backend de Gestión de Eventos y Recursos Académicos</b></summary>
<br>

API RESTful modular diseñada para la administración integral de eventos, inscripciones, control de asistencia, pagos y emisión de certificados.

| Atributo | Detalles |
| :--- | :--- |
| **Stack** | TypeScript, NestJS, Docker, pnpm |
| **Scale** | Arquitectura estructurada en más de 15 módulos de dominio (Usuarios, Eventos, Facultades, Pagos, Notas). |
| **Performance** | Entorno containerizado mediante Docker (`docker-compose.yaml`) para garantizar un despliegue optimizado y ambientes consistentes. |
| **Security** | Gestión integral de roles de usuario, tipos de participantes y control de requerimientos de inscripción. |
| **Impact** | Centraliza la lógica de negocio para la gestión académica extracurricular, automatizando el flujo de datos desde la inscripción hasta la facturación y certificación. |
| **Repository** | [Ver Repositorio](https://github.com/javierpea/proyecto-manejo-backend) |

**Professional Explanation:**
Desarrollado aplicando principios de arquitectura modular con NestJS, lo que asegura un bajo acoplamiento y alta cohesión entre los servicios backend. El sistema gestiona relaciones de datos complejas involucrando parámetros de tarifas de eventos, historiales de notas, solicitudes de cambio y control de asistencia, proveyendo un núcleo sólido y escalable para la operatividad académica.

<details>
<summary><b>💼 Sistema de Facturación Electrónica y Gestión de Inventarios (SOA)</b></summary>
<br>

Plataforma integral con arquitectura orientada a servicios (SOA) para el control de facturación comercial, sincronización con entidades fiscales (SRI) y administración de inventarios.

| Atributo | Detalles |
| :--- | :--- |
| **Stack** | Java, Spring Boot, Maven, JWT, Thymeleaf |
| **Scale** | Múltiples submódulos de gestión operativa abarcando sucursales, clientes, productos, categorías y reportes. |
| **Performance** | Integración eficiente de vistas renderizadas en el servidor e interacciones con servicios SOAP (`SriSoapService`) para procesamiento transaccional. |
| **Security** | Implementación robusta mediante JSON Web Tokens (JWT) y cifrado de datos a través de filtros de autenticación personalizados de Spring Security. |
| **Impact** | Automatiza el ciclo de vida fiscal, abarcando la generación de documentos comerciales, firmado electrónico y estructuración de comprobantes (RIDE). |
| **Repository** | [Ver Repositorio](https://github.com/javierpea/facturacion-Srpringboot-SOA) |

**Professional Explanation:**
Construido sobre el ecosistema de Spring, el sistema implementa un diseño de capas altamente estructurado (Controladores, Servicios, Repositorios). Destaca la ingeniería detrás de la facturación fiscal, integrando utilidades criptográficas para la firma electrónica de documentos, generación lógica de claves de acceso y estructuración de comprobantes según la normativa vigente, manteniendo la integridad de las transacciones mediante seguridad basada en tokens.
</details>
